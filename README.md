# .github

本仓承载 rvbench 组织的公共配置，GitHub 会自动读取：

| 路径 | 作用 |
|---|---|
| `profile/README.md` | 组织主页 [github.com/rvbench](https://github.com/rvbench) 展示的 README（英文，GitHub 默认读取此文件） |
| `profile/README.zh-CN.md` | 上述 README 的简体中文版，由主页顶部语言切换进入 |
| `profile/assets/` | README 使用的品牌素材：`rvbench-logo.svg`（浅色）、`rvbench-logo-dark.svg`（深色） |

依据 GitHub 组织 profile 约定：公开仓 `.github` + `profile/README.md`。改动走 PR。

中英两份内容需同步修改：`profile/README.md`（en）与 `profile/README.zh-CN.md`（zh-CN），两者的章节结构与链接保持一致。
